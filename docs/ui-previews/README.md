# UI previews

LiteLLM-like light shell (sidebar, thin borders, near-black buttons) plus Relic-like idea table. For **screen alignment**.

- PNG: live `pnpm dev` captures. Desktop ~1280px / mobile ~390px.
- SVG: compact GitHub-renderable sketches (binary PNG upload from this agent path corrupts files).

Product UI copy in the captures is Japanese. This index is English.

There is **no landing page**. `/` redirects to `/login`.
